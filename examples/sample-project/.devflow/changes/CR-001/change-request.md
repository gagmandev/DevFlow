## 变更内容

订单退款后，原先发给用户的积分不能直接扣掉（用户可能已经花掉）。改为**冻结**等额积分：

- 冻结：`balance` 不变，`frozen += amount`，`available` 减少；
- 解冻：`frozen -= amount`，`available` 恢复；
- 冻结期间这部分积分不能用于兑换；
- 冻结与解冻都要留流水（`frozen_delta`），余额变动仍记在 `amount`。

## 变更原因

v1 把退款回收列为 OPEN-001，靠人工改余额，无法审计。退款流程即将上线，必须先有冻结能力。
